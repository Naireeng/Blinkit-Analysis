## 📌 Project Overview

This project focuses on analyzing Blinkit's grocery sales data using SQL and Power BI to evaluate sales performance, product categories, outlet characteristics, and location-based trends. The interactive dashboard provides a consolidated view of key business metrics and helps identify patterns across different outlet types, sizes, and locations.

## 🎯 Project Objectives

- Analyze overall sales performance and key performance indicators (KPIs).
- Evaluate sales contribution by fat content and item type.
- Compare outlet performance across establishment years, sizes, and locations.
- Analyze total sales, average sales, item counts, and customer ratings.
- Build an interactive Power BI dashboard to support data-driven decision-making.

## 🛠️ Tools & Technologies

- **SQL** – Data querying, aggregation, filtering, and analysis.
- **Power BI** – Dashboard development, data visualization, and interactive reporting.
- **DAX** – KPI calculations and measures, where applicable.
- **Data Analysis** – Identifying trends and comparing business performance.

## 📈 Dashboard Insights & Visualizations

### 1. Sales Performance
- Tracks total sales and average sales across the business.
- Compares sales performance across different outlet types.
- Highlights the contribution of individual product categories.

### 2. Fat Content Analysis
- Compares sales generated by Low Fat and Regular fat-content products.
- Visualizes fat-content sales distribution.
- Examines fat-content performance across outlet locations.

### 3. Item Type Analysis
- Compares sales across product categories, including fruits and vegetables, snack foods, household products, frozen foods, and dairy.
- Identifies product categories contributing to overall sales.

### 4. Outlet Establishment Analysis
- Visualizes sales performance by outlet establishment year.
- Enables comparisons across outlets established in different years.

### 5. Outlet Size Analysis
- Compares sales contributions from small, medium, and high-sized outlets.
- Highlights differences in sales performance across outlet sizes.

### 6. Outlet Location Analysis
- Evaluates sales across Tier 1, Tier 2, and Tier 3 locations.
- Compares location-wise contributions to total sales.

### 7. Outlet Type Analysis
- Compares Grocery Stores and different Supermarket types.
- Analyzes total sales, number of items, average sales, average ratings, and item visibility.

## 🔍 SQL Analysis

SQL was used to explore the dataset and analyze sales performance through queries involving:

- Data filtering and sorting.
- Aggregate functions such as `SUM()`, `AVG()`, and `COUNT()`.
- Grouping and comparison using `GROUP BY`.
- Analysis of sales by item type and outlet characteristics.
- Extraction of meaningful summaries to support dashboard development.
